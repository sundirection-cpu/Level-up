# LEVEL UP — прокачка жизни

Пиксельное RPG-приложение для саморазвития. Сделано по мотивам цикла «Level Up» Данияра Сугралинова: обычная жизнь выглядит как интерфейс игры, а за реальные дела начисляется опыт.

## Запуск
- **На компьютере:** запусти `./start.sh`. Откроется http://localhost:8765.
- **Как приложение:** в Chrome открой меню и выбери «Установить приложение». Оно будет работать и без интернета.
- **На телефонах семьи:** приложение нужно разместить на HTTPS-хостинге, например на GitHub Pages или Netlify. После этого его можно добавить на экран «Домой».

## Что внутри
- **Герои семьи (гильдия).** У каждого свой персонаж: пиксельный аватар, уровень, титул и HP.
- **8 характеристик = 8 сфер жизни:** Сила (тело), Выносливость (здоровье), Интеллект (учёба), Харизма (семья), Воля (дисциплина), Творчество, Достаток (работа и финансы), Дух (осознанность).
- **Привычки.** Задаются по дням недели и сложности. Есть серии с бонусом к опыту и 5% шанс критического успеха (×2). Если все привычки дня выполнены, засчитывается «Идеальный день».
- **Дебаффы (вредные привычки).** Считаются чистые дни, за вехи 1/3/7/14/30… дней даются награды. Срыв отнимает HP.
- **Квесты (цели).** У каждого ранг от E до S, шаги, срок и награда по рангу.
- **Задание дня от Системы.** Каждый день новое.
- **Состояние:** настроение и бодрость. От них зависят баффы и дебаффы.
- **27 достижений.** На 20 уровне герой получает корону на аватар.
- **Лавка наград.** Свои награды покупаются за заработанное золото.
- **Журнал Системы**, 8-битные звуки, уведомления о новом уровне.

## Данные
Данные хранятся в браузере устройства (localStorage). Резервную копию можно сохранить и загрузить в Настройках (шестерёнка).
