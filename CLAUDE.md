# KinLevel — заметки для Claude

## Что это
KinLevel (раньше назывался Level Up) — пиксельное RPG-приложение для всей семьи: каждый член семьи — герой со своим уровнем, 8 характеристик = 8 сфер жизни, привычки, квесты, ачивки, лавка наград. Слоган: «Прокачай свой род».

## Правила
- **Никаких отсылок к книге «Level Up» Данияра Сугралинова.** Не использовать слова и термины из книги: «Интерфейс», «Система», имя «Фил» и т. п. Только общеигровые RPG-термины (квест, ежедневный квест, летопись, лавка, ачивки, баффы/дебаффы, ранги E–S).
- Название **KinLevel** проверено: товарных знаков и приложений с таким именем не нашлось (ноябрь 2026). Важны рынки Бразилия, США, ЕС; Россия — второстепенно.
- Три языка интерфейса: русский, английский, португальский (Бразилия). Все тексты — в `i18n.js`; любые новые строки добавлять на всех трёх языках.
- Логотип — пиксельный герб (корона, семейное древо, два восходящих шеврона), спрайт `crest` в `sprites.js`; иконки сгенерированы из него.

## Как устроено
- Чистый HTML/CSS/JS без сборки: `index.html`, `style.css`, `sprites.js` (вся графика в коде), `i18n.js`, `app.js`, `sw.js` (офлайн; после изменений поднимать `VERSION`).
- Данные — в localStorage (`kinlevel.v1`; старый ключ `levelup.v1` переносится автоматически).
- Запуск: `./start.sh` → http://localhost:8765.
- Звук и фоновая музыка — свои, на Web Audio (`sfx()`, `musicStep()` в app.js). Шаг квеста = 100 золота (`STEP_GOLD`). Подработка «Чем тебе помочь?» — `p.jobs`, панель во вкладке «Квесты» (с 2026-11-24, версия 2.1).

## APK для Android
- Собирается **только на компьютере владельца**: `./android/build-apk.sh` → `KinLevel.apk` в корне проекта. Инструменты и ключ подписи лежат в `~/.local/share/android-build` (`kinlevel.keystore` — не терять).
- Из облачной сессии собрать APK нельзя (нет SDK и ключа). Если пользователь просит APK из облака — сразу сказать, что сборка идёт на компьютере.
- Пакет: `app.kinlevel.family`. Перед новой сборкой поднимать `versionCode`/`versionName` в `android/AndroidManifest.xml`.
